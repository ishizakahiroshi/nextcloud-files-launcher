# Security policy

This candidate has not completed its public release review. Compatibility is limited to the declared Nextcloud version.

Do not open a public issue containing credentials, private file names or live-server exploit details. After publication, use GitHub private vulnerability reporting if enabled. If unavailable, contact the maintainer through the public profile's listed contact method to arrange a private report. A report is not confirmed received until acknowledged.

Provide the app/Nextcloud versions, expected access boundary and a minimal synthetic reproduction. Do not attach production data.
